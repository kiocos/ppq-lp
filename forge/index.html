Estudo · a forja como material, não como cena

Sem ferreiro. Quem forja é o visitante.

A pintura mostrava outra pessoa trabalhando. Aqui o produto é a peça na bigorna, e o calor é a linguagem da página: um só movimento, de quente para frio, que só aparece onde algo está sendo feito agora.

Build · o metal

Uma barra de aço renderizada em tempo real. Fria nas pontas, quente onde o trabalho acontece: embaixo da resposta enquanto o modelo escreve, e onde o cursor passa perto.

IA · tokens em brasa

Cada token chega incandescente e esfria em pouco mais de um segundo. A resposta é forjada na frente do visitante, no produto real, e não numa ilustração.

Privacidade · o hallmark

Há mais de 700 anos a prata inglesa é testada por um órgão independente e marcada no Goldsmiths' Hall; daí a palavra hallmark. As quatro punções são as quatro checagens que o navegador faz antes de enviar: fabricante, hardware AWS Nitro, PCR0 e versão.

Marca · uma cor só

O laranja do botão (#bf3c1b) é a cor exata do metal a meio calor. Na pintura havia dois laranjas diferentes, e parecia erro.

O que é real e o que é encenado

  • Real: o composer replica o do app; os nomes de modelos, a base URL da API e o PCR0 bd2b83ae…5de85c10 da build v0.75.0, publicado em 13 nov 2026 em PayPerQ/ppq-enclave-proxy.
  • Encenado: as respostas foram escritas por mim, sem chamar nenhum modelo. A verificação é uma sequência cronometrada, não uma checagem de attestation de verdade.
  • Para publicar: a checagem precisa rodar de verdade no navegador, o que exige que o endpoint de attestation aceite CORS. Se não der, as punções saem: simular uma verificação para esse público seria pior do que não ter.

Experimente

  • Passe o cursor perto da barra de metal, ou digite no composer: o metal esquenta.
  • Troque entre Chat e API no topo do card. Passe o mouse nas punções para ler cada checagem.
