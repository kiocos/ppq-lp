Your chats stay unreadable to us.

Your browser encrypts each chat to a key that exists only inside a secure enclave, an isolated piece of hardware. Our servers, databases and logs only ever hold noise.

PayPerQ sees the model, token counts and timing, never the words. What the model provider sees depends on the model you pick, and every model is labelled.

Anon 226 models

The provider reads your prompt and may keep it under its own policy. It never receives your IP address.

Zero data retention 156 models

The provider processes the request under an agreement not to store prompts or replies.

End-to-end encrypted 6 models

The model itself runs inside an enclave, so even its host can't read the conversation.

This covers chat, in the web app and the API. Image, video and audio requests take different paths.

Built to be checked

The enclave's code is public and its build is reproducible. Before sending anything, your browser asks the enclave to prove which code it runs, then compares that measurement with the one published on GitHub. If they differ, nothing is sent.

Your models can work beyond this chat.

Point any OpenAI-compatible tool at PayPerQ. Chat completions on api.ppq.ai go through the same secure enclave, with nothing to change on your side.

from openai import OpenAI client = OpenAI( base_url="https://api.ppq.ai/v1", api_key=os.environ["PPQ_API_KEY"], ) reply = client.chat.completions.create( model="claude-sonnet-5.5", messages=[{"role": "user", "content": "Hello"}], )
import OpenAI from "openai"; const client = new OpenAI({ baseURL: "https://api.ppq.ai/v1", apiKey: process.env.PPQ_API_KEY, }); const reply = await client.chat.completions.create({ model: "claude-sonnet-5.5", messages: [{ role: "user", content: "Hello" }], });
curl https://api.ppq.ai/v1/chat/completions \ -H "Authorization: Bearer $PPQ_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model": "claude-sonnet-5.5", "messages": [{"role": "user", "content": "Hello"}]}'

One line changes: the base URL. Everything else is the client you already use.
