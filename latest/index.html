Frequently asked questions.

What is PayPerQ?

One place to use the major AI models privately: Claude, GPT, Gemini, Grok, DeepSeek, Kimi and hundreds more, in a chat app and an OpenAI-compatible API. You top up a prepaid balance and pay per message. No subscription, and no account required.

Can PayPerQ read my chats?

Not the messages you send. Every chat request, from the web app or the API, is served inside an AWS Nitro Enclave: isolated hardware that neither PayPerQ staff nor AWS can log in to. The TLS connection from your device ends inside the enclave, so your prompt and the reply are decrypted only there. PayPerQ’s servers get billing metadata only: your credit ID, the model, token counts and timestamps.

Saved history is a separate question. With no account or with a passkey, PayPerQ can’t read it either. With an email, Google or GitHub account, the synced copy on PayPerQ’s servers isn’t end-to-end encrypted. Where chats are stored

Not covered yet: image, video and audio requests go through PayPerQ’s backend, which doesn’t log them but can’t prove it yet. Your IP address is visible at the network edge, as on any website. How the Enclave Router works

Where are my chats stored?

It depends on how you sign in. Every message goes through the enclave on its way to the model; this is about the history kept afterwards.

No account
Only in your browser. Nothing is saved on PayPerQ’s servers. Clear the browser’s data and the chats are gone: your credit ID restores the balance, not the chats.
Email, Google or GitHub
In your browser, plus a copy on PayPerQ’s servers so the chats follow you to other devices. That copy isn’t end-to-end encrypted. Deleting the account deletes it.
Passkey
In your browser, plus a copy on PayPerQ’s servers that your browser encrypts with AES-256-GCM first. PayPerQ stores only ciphertext and never holds the key. Turning on a passkey encrypts the chats you already have and deletes any readable copies from the server.
API
PayPerQ keeps no conversation content; your app stores what it sends. The query log holds metadata only: time, model, tokens and price.

A passkey has no reset, so keep it in a manager that syncs it, such as iCloud Keychain or 1Password. How passkey-encrypted chats work

Can the AI provider see my messages?

It depends on the model, and every model shows a badge. On most models the provider reads the prompt, because that’s where the model runs. It receives it from PayPerQ’s enclave under PayPerQ’s credentials, not yours.

Anon
The provider may keep prompts under its own policy, with no link to you.
ZDR
Sent only to Zero Data Retention endpoints. Nothing is stored or used for training.
E2EE
The model runs inside a Tinfoil enclave on NVIDIA confidential-computing GPUs, so the provider can’t read the prompt either.

OpenAI requires a per-user ID, so its models receive a one-way keyed hash it can’t reverse. Anon vs ZDR vs TEE

How can I check this myself?

The enclave’s code is open source (PayPerQ/ppq-enclave-proxy) and reproducibly built. Before sending, your browser fetches the enclave’s AWS-signed attestation and compares its code fingerprint (PCR0) with the published build. If they differ, nothing is sent.

To run the check on your own machine, start the open-source PPQ Privacy Verifier and point any OpenAI- or Anthropic-compatible client at http://127.0.0.1:8787.

PPQ_API_KEY=sk-… npx ppq-private-mode
How do I know I got the model I chose?

Every streamed reply carries a routing receipt signed by the enclave. It names the model you asked for, the provider the enclave connected to and the exact model ID it sent. The enclave’s code also ties each model family to its own provider, with OpenRouter as the only fallback, so a request for Claude can’t be quietly answered by a cheaper model.

Check a receipt’s signature with verify-receipt.mjs in the enclave repo.

Do I need an account?

No. Topping up gives you a credit ID, and that’s all PayPerQ needs. It works like cash: whoever holds it can spend the balance, and PayPerQ can’t recover it for you, so save it somewhere safe. For a way back in, add an email, Google or GitHub login, or a passkey.

How much does it cost?

Nothing monthly. Top up from $0.10, and each message is billed by its tokens at that model’s price: a short reply from a small model costs a fraction of a cent, a long one from a frontier model costs more. Most people spend about $4 a month.

Every model’s price is on the pricing page and at v1/models.

How can I pay?

Bitcoin on-chain or over Lightning, Monero, Litecoin, Liquid Bitcoin, USDT, USDC, or a card through Stripe. Lightning top-ups get a 5% bonus, and a Nostr Wallet Connect wallet can top up automatically when your balance runs low. Gift cards are sold on Bitrefill.

Paying by card links the card to your credit ID at PayPerQ, though never at the model provider. Pay with crypto if that matters to you.

Can I use PayPerQ in Claude Code, Cursor or my own app?

Yes. Create an API key and set the base URL to https://api.ppq.ai/v1: the OpenAI SDKs and most AI tools work unchanged. A native Anthropic Messages endpoint lets Claude Code run with ANTHROPIC_BASE_URL=https://api.ppq.ai. PayPerQ sets no rate limits; your balance is the only cap.

Setup guides for Claude Code, Codex, Cursor, OpenCode and more are on the blog.
