Know what your model provider can see. Each model carries a privacy label, so you can choose the protection a task needs.

Anon 226 models

The provider can read your prompt and may keep it under its own policy. It never receives your IP address.

Zero data retention 155 models

The provider processes the request under an agreement not to store prompts or replies.

End-to-end encrypted 6 models

The model itself runs inside a protected enclave, so even its host cannot read the conversation.

This protection covers chat, in the web app and the API. Image, video and audio requests take different paths.

Your models can work beyond this chat.

Point any OpenAI-compatible tool at PayPerQ. Chat completions on api.ppq.ai go through the same secure enclave, with nothing to change on your side.

curl https://api.ppq.ai/v1/chat/completions \ -H "Authorization: Bearer $PPQ_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model": "claude-sonnet-5.5", "messages": [{"role": "user", "content": "Hello"}]}'
from openai import OpenAI client = OpenAI(base_url="https://api.ppq.ai/v1", api_key=os.environ["PPQ_API_KEY"]) reply = client.chat.completions.create( model="claude-sonnet-5.5", messages=[{"role": "user", "content": "Hello"}], )
import OpenAI from "openai"; const client = new OpenAI({ baseURL: "https://api.ppq.ai/v1", apiKey: process.env.PPQ_API_KEY }); const reply = await client.chat.completions.create({ model: "claude-sonnet-5.5", messages: [{ role: "user", content: "Hello" }], });
