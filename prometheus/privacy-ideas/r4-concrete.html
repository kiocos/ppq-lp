Privacy

Private by hardware, not by promise.

Every chat runs inside an AWS Nitro Enclave. Follow one message through it.

AWS Nitro EnclavesTLSRemote attestationOpen source on GitHub

01

You write a message.

In the PayPerQ app, or through the API.

02

TLS encrypts it all the way into the enclave.

The TLS connection ends inside the AWS Nitro Enclave, not on our web servers.

03

Our servers only see ciphertext.

Plus what billing needs: the model, the token count, the time.

04

It’s decrypted inside an AWS Nitro Enclave.

An isolated environment enforced by AWS hardware: no shell, no disk, no admin access. Our staff, our logs and the host machine can’t read its memory.

05

The enclave sends it to the model provider, without your IP.

Each streamed reply carries a routing receipt, signed inside the enclave, naming the provider that served it.

06

Don’t trust us. Check.

AWS signs a fingerprint (PCR0) of the code running in the enclave. Your browser compares it with the open-source build on GitHub before you send.

Reproducible build · Sigstore-attested on GitHub Actions · PayPerQ/ppq-enclave-proxy

07

Or check it from your terminal.

Our open-source verifier fetches the attestation, checks it against the published PCR0, and refuses to send anything if they differ.

Works with any OpenAI- or Anthropic-compatible client · PayPerQ/ppq-privacy-verifier
